- 用一栏式线性布局，不要两栏（ATS经常把两栏内容读乱）
- 导出为标准PDF，不要用图片/扫描件/特殊字体

- 项目经历按时间倒序，AI项目放在最前面
- 所有数据量化：用X%、X秒、X万、X人天

- 不要放头像、照片、性别、年龄、婚姻状况（反而容易触发歧视筛选）

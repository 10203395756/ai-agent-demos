# 快速启动指引（面试演示专用）

## 1分钟跑起来
```bash
cd ai-agent-demos
bash start.sh
```
然后打开 http://localhost:8000/docs ，在Swagger页面直接点"Try it out"测试接口。

## 三个核心测试用例（面试演示顺序）

### 1. 先演示Demo2（多工具调用，效果最直观）
POST `/api/v1/agent/chat`，body：
```json
{"message": "帮我算一下1299打85折再减50是多少钱，顺便查一下贵阳今天天气"}
```
→ 可以看到自动调用calculator和get_weather两个工具，返回tool_calls轨迹

### 2. 再演示Demo1（RAG知识库）
第一步先入库：POST `/api/v1/rag/ingest`，body：
```json
{
  "text": "LangGraph是LangChain团队推出的多智能体编排框架，基于StateGraph状态图构建。核心概念包括State、Node、Edge、Checkpointer，支持多Agent协作和Human-in-the-loop人机协同。",
  "source": "面试演示文档.md"
}
```
第二步提问：POST `/api/v1/rag/query`，body：
```json
{"question": "什么是LangGraph？核心概念有哪些？"}
```
→ 可以看到基于知识库回答、来源引用、session_id

### 3. 最后演示Demo3（多智能体+人机协同，这是最核心的）
POST `/api/v1/multi-agent/submit`，body：
```json
{"message": "帮我调研一下LangGraph企业级落地最佳实践"}
```
→ 返回status="waiting_human_review"，拿到thread_id后
POST `/api/v1/multi-agent/feedback`，body：
```json
{"thread_id": "上面返回的thread_id", "feedback": "通过"}
```
→ 继续执行，返回最终汇总回答

## 演示亮点话术（边操作边说）
1. "这个项目默认Mock模式，不需要任何API Key就能跑完整链路——这是为了面试和评审方便，切换.env一个配置就是真实大模型"
2. "您看这里，工具调用是有完整轨迹的，每一步调了什么、参数是什么、返回了什么，都能追踪——生产环境问题排查靠这个"
3. "多Agent这里是真正的人机协同，到关键节点自动中断等人确认，不是假的人工开关——这是用LangGraph的interrupt_before实现的"
4. "服务层做了限流、SSE流式、Prometheus监控、TraceID全链路追踪，这些是生产级必须的，不是玩具Demo"
